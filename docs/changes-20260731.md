## 二、系统设置 — UI 自定义 Tab

### 2.1 新增 UI 自定义配置项
在「系统设置」页面新增「UI 自定义」Tab，支持以下配置：

| 字段 | 说明 | 环境变量 |
|------|------|---------|
| `system_home_icon` | 系统首页图标（base64） | `KVM_SYSTEM_HOME_ICON` |
| `home_title` | 首页标题/侧边栏产品名 | `KVM_HOME_TITLE` |
| `login_page_icon` | 登录页图标（base64） | `KVM_LOGIN_PAGE_ICON` |
| `product_name` | 产品名称（登录页显示） | `KVM_PRODUCT_NAME` |
| `browser_favicon` | 浏览器 Favicon（base64） | `KVM_BROWSER_FAVICON` |
| `browser_title` | 浏览器标签页标题 | `KVM_BROWSER_TITLE` |
| `footer_text` | 页脚版权信息（留空使用默认格式） | `KVM_FOOTER_TEXT` |
| `footer_link` | 页脚超链接（留空则纯文本展示） | `KVM_FOOTER_LINK` |

## 四、Bug 修复

### 4.1 IconBrush 导入错误
- **文件**：`web/src/views/settings/index.tsx`
- **问题**：`IconBrush` 在 semi-icons 中不存在，导致系统设置页报错
- **修复**：替换为 `IconColorPalette`

### 4.2 vgpu_profiles 列名错误
- **文件**：`server/model/vgpu.go`、`server/model/db.go`
- **问题**：GORM 蛇形命名将 `PCIDevice` 错误转换为 `pc_idevice`，而代码查询使用 `pci_device`，导致 `Unknown column 'pci_device' in 'order clause'` 错误
- **修复**：
  - 模型添加 `column:pci_device` 显式指定列名
  - 新增 `migrateVGPUProfilePCIDeviceColumn()` 迁移函数，自动将旧列 `pc_idevice` 重命名为 `pci_device`（支持 MySQL CHANGE COLUMN）
  - 手动修复当前数据库（重命名列 + 补建索引）

### 4.3 vGPU discover 接口 404
- **文件**：`web/src/api/settings.ts`
- **问题**：前端调用 `/host/vgpu/discover`，后端注册 `/host/vgpu/profiles/discover`，路径不一致
- **修复**：前端路径改为 `/host/vgpu/profiles/discover`
